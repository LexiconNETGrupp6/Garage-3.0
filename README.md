## **Instruktioner**:
### Registera nytt Fordon
- Tryck på "Register New Vehicle"
- Skriv in info och tryck på "Register"<br>

Admins can see and manage every vehicle while members can only see and manage their own
### Parkera
- Hitta fordonet i listan och tryck på "Park Vehicle" alternativt gå till "Details" sedan "Park Vehicle"
- Välj en ruta. Sedan klar
### Checka Ut
- Hitta fordonet i listan och tryck på "Details"
- Tryck på "Checkout Vehicle"  
- Tryck på "Confirm". Sedan klar
### (Admin) Hantera Medlemmar
- Gå till "Members"
- Tryck på "Details" för att se deras roller, fordon och kostnader
- Tryck på "Edit" för att göra medlemmen till Pro-Member, Admin, eller vanlig Member
- Tryck på "Delete" och sedan "Confirm Delete" för att ta bort kontot
